# Bootstrap Consensus Graph (T=103)

This folder contains the reproducible pieces for the bootstrap consensus graph used for the `bootstrap_103` path experiments.

Run all commands from the repository root.

## Inputs

- `bootstrap/coad2(in).csv`: COAD2 mutation matrix used as the bootstrap source.
- `bootstrap/CreateBootstrapDatasets.R`: creates 200 bootstrap sample-column resamples.
- `bootstrap/create_bootstrap_graph.R`: builds per-resample directed edges and aggregates them into a consensus edge table.
- `bootstrap/minimum_t.R`: finds the minimum edge-frequency threshold that yields a DAG and exports the T=103 paths.

## Generated Files

These files are generated by the scripts:

- `bootstrap/bootstrap_datasets/dataset_*.csv`
- `bootstrap/data/edges/*_edges.csv`
- `bootstrap/data/batch*_consensus_edges.csv`
- `bootstrap/data/Beforecycles_removed.csv`
- `bootstrap/data/t_min_dag_graph.rds`
- `bootstrap/data/topological_order_103.txt`
- `bootstrap/data/longest_path_unweighted_103.txt`
- `bootstrap/data/longest_path_weighted_103.txt`

## Workflow

1. Create the bootstrap datasets:

```bash
Rscript bootstrap/CreateBootstrapDatasets.R
```

2. Build the consensus edge table:

```bash
Rscript bootstrap/create_bootstrap_graph.R
```

3. Find the T=103 DAG and export paths:

```bash
Rscript bootstrap/minimum_t.R
```

The exported path files can then be supplied to `mutation_prediction.py` with `--lp_txt` and `--topo_txt`.
